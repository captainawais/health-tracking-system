# 🏥 Health Tracking System

A modern and interactive **Health Tracking Web Application** built using HTML, CSS, and JavaScript.
This project helps users monitor their health activities like hydration, fitness, and daily routines.

## ✨ Features

* 🔐 Login & Register System (Local Storage Based)
* 🎯 Smart Loader (Only shows after login)
* 🌙 Dark Mode (Persistent)
* 📱 Fully Responsive (Mobile + Desktop)
* 🎨 Modern UI Design
* ⚡ Fast Performance (No frameworks)

---

## 🧠 How It Works

1. User registers with username & password
2. Data is saved in **LocalStorage**
3. User logs in using same credentials
4. After login → smart loader appears
5. User navigates through health tracking pages
